# ADR 0003: Estrategia SEO Local

## Status

Accepted

## Context

We need an SEO strategy to rank for local plumbing searches.

Requirements:
- Comply with Google's guidelines
- Provide real value to users
- Avoid spammy tactics
- Sustainable long-term growth

## Decision

We will use a **quality-first, slow-growth approach**:

### Phase 1: Foundation (Months 1-2)

- Technical SEO setup
- Homepage optimization
- 5-10 test city pages
- Basic content

### Phase 2: Validation (Months 3-4)

- Add real plumber data
- Expand to 20-50 cities
- Improve content quality
- Monitor rankings

### Phase 3: Scale (Months 5+)

- Add more cities with real data
- Build backlinks
- Optimize based on analytics
- Consider paid acquisition

### Rules

**DO:**
- Create unique, valuable content per city
- Only create pages with real data
- Optimize for user intent
- Build natural backlinks

**DON'T:**
- Auto-generate thousands of pages
- Duplicate content
- Create thin content
- Buy links or use black-hat tactics

## Consequences

### Positive

- Sustainable growth
- No Google penalties
- Better user experience
- Long-term value

### Negative

- Slower initial growth
- More work per page
- Need real data for each city

### Neutral

- Requires ongoing content creation
- Need to monitor rankings

## Alternatives Considered

- **Programmatic SEO**: Fast but risky, can get penalized
- **Paid ads**: Expensive, stops when budget stops
- **Directory submissions**: Low quality, time-consuming
- **Content farms**: Low quality, can get penalized

## Metrics

- Organic traffic growth
- Keyword rankings
- Click-through rate
- Bounce rate
- Time on page
